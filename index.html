AI Mirror Translation & Editing Suite

Welcome to the zero-backend document translation suite. This workspace allows you to translate dense multi-lingual PDF files (Arabic, Urdu, English) directly into Bangla or English while preserving visual document layouts, embedded images, and footnoting structures.

API Key Setup

  1. Obtain a Gemini API Key from Google AI Studio.
  2. Open any translator app page from the left sidebar menu.
  3. Click the Settings (Gear Icon) in the top header.
  4. Paste your API Key. You can enter up to 10 keys for automatic rotation when rate limits are hit.

AI Limitations & Important Rules

  • Content Drift: Academic/religious texts with dense footnotes can occasionally cause sentence-bleed. Use the built-in Verify feature to perform automated proofreading.
  • Rate Limits: Free-tier Gemini models enforce Daily/Minutely request caps. The system handles automatic exponential backoff pacing automatically.

Privacy & Client-Side Safety

All document processing occurs entirely client-side in your web browser. API keys are stored strictly in session memory (or optional local browser storage) and are transmitted directly to Google's official Gemini API endpoints. No intermediary server or tracking database exists.
